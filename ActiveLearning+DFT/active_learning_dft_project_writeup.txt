
# Active Learning + DFT for Lithium Diffusion Barrier Prediction
## Project Writeup and Technical Blueprint

# 1. Project Overview

## Project Title

Multi-Fidelity Active Learning Framework for DFT-Accurate Lithium Diffusion Barrier Prediction

# 2. Scientific Motivation

Lithium-ion transport plays a central role in:
- solid-state batteries,
- cathode materials,
- ionic conductors,
- electrochemical devices.

The key physical quantity controlling ionic mobility is the migration barrier:

E_a = E_saddle - E_initial

The diffusivity depends exponentially on the migration barrier:

D ∝ exp(-E_a / (k_B T))

Even small prediction errors in E_a can lead to orders-of-magnitude errors in diffusivity.

# 3. Problem Statement

## Challenge

DFT-NEB calculations are:
- computationally expensive,
- time-consuming,
- difficult to scale.

Large-scale materials screening becomes impractical.

## Goal

Develop an ML-driven active learning framework that:
- predicts migration barriers accurately,
- minimizes expensive DFT calculations,
- intelligently selects the most informative structures for DFT evaluation.

# 4. Core Idea

Instead of computing all barriers using DFT:

1. Train an ML surrogate.
2. Estimate uncertainty.
3. Selectively query DFT only where needed.

This creates a closed-loop autonomous discovery pipeline.

# 5. Existing Dataset

## High-Fidelity Dataset

DFT-NEB Dataset
Approximate size:
- ~1,600 barriers.

Properties:
- accurate,
- expensive,
- ground truth.

Each sample contains:
- crystal structure,
- atomic positions,
- hopping pathway,
- saddle-point information,
- migration barrier.

## Low-Fidelity Dataset

BVSE Dataset
Approximate size:
- ~122,000 barriers.

Properties:
- cheap,
- approximate,
- physically informed.

# 6. Multi-Fidelity Formulation

The model learns:

E_DFT = E_BVSE + ΔE

where:
- BVSE captures coarse electrostatics,
- ML learns quantum/mechanical corrections.

- equivariant GNN.

G = (V,E)

where:
- V = atoms,
- E = neighbor interactions.

## Output

G -> E_a

## Suggested Architecture

Encoder:
- message-passing layers.

- global graph embedding.

Regression head:
- 128 -> 64 -> 1

# 10. Uncertainty Quantification

## Recommended Approach

Ensemble Models

Train:
f_1, f_2, ..., f_n

Prediction:
μ(x) = (1/n) Σ_i f_i(x)

Uncertainty:
σ²(x) = (1/n) Σ_i (f_i(x) - μ(x))²

# 11. Active Learning Framework

## Initial Seed Set

Randomly select:
- 50–200 DFT samples.

Train initial model.

## Candidate Pool

Remaining structures become:
- unlabeled pool.

## Iterative Loop

Step 1:
Train model.

Step 2:
Predict:
- mean barrier,
- uncertainty.

Step 3:
Select new samples using acquisition function.

Step 4:
Reveal hidden DFT labels.

Step 5:
Retrain.

Repeat until convergence or DFT budget exhaustion.

# 12. Acquisition Functions

## Method 1 — Uncertainty Sampling

x* = argmax σ(x)

## Method 2 — Diversity Sampling

Avoid redundant structures.

Possible methods:
- k-center greedy,
- clustering,
- farthest-point sampling.

## Method 3 — Hybrid Acquisition

A(x) = α σ(x) + β D(x)

## Method 4 — Physics-Guided Acquisition

Use:
- local coordination,
- electrostatic descriptors,
- symmetry,
- bond topology,
- diffusion geometry.

# 13. Data Splitting

MAE:
MAE = (1/N) Σ_i |y_i - ŷ_i|

RMSE:
RMSE = sqrt((1/N) Σ_i (y_i - ŷ_i)^2)

R² score.
